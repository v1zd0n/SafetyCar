# Демо маршрут и интерфейс към backend

`/` е презентацията. Бутонът **Демо** отваря `/demo` с примерен маршрут. При липса на `VITE_ROUTE_API_URL` изборът остава ограничен до пет града по коридора София–Бургас и резултатите са примерни.

За свързване на backend задайте `VITE_ROUTE_API_URL` в `.env` и върнете JSON от `POST` заявка:

```json
{
  "origin": { "id": "sofia", "name": "София", "coordinates": [23.3219, 42.6977] },
  "destination": { "id": "stara-zagora", "name": "Стара Загора", "coordinates": [25.62, 42.425] },
  "vehicleType": "car"
}
```

`vehicleType` е `car` или `truck`. Координатите са `[longitude, latitude]` в WGS84. Очакван отговор:

```json
{
  "id": "route-123",
  "distanceKm": 250,
  "durationMinutes": 180,
  "geometry": [[23.3219, 42.6977], [23.4, 42.65], [25.62, 42.425]],
  "risks": [
    {
      "id": "segment-1",
      "name": "Вакарел — Ихтиман",
      "road": "A1 · Тракия",
      "level": "high",
      "description": "Повишен риск",
      "lengthKm": 18.4,
      "geometry": [[23.615, 42.538], [23.74, 42.484]]
    }
  ]
}
```

`level` е `high`, `medium` или `low`. Геометрията на всеки рисков участък трябва да лежи върху върнатия маршрут. При зададен backend URL грешките се показват на потребителя; примерните данни не заместват мълчаливо отговор от сървъра.

Вграденият сървър взема маршрут от Mapbox Directions и след това оценява обхванатите участъци по него. Връща участъците със среден или висок риск според базовата оценка и наличните актуални съобщения от АПИ за избрания вид МПС. Видът МПС влияе върху отчитането на съобщенията по трасето.
